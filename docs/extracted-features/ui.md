# Legacy Feature Documentation: UI & Design Aesthetics

This document describes the design style, components, and layout aesthetics.

---

## 1. Visual Aesthetics & Themes

- **Glassmorphism & Gradients**: Premium looking elements with subtle box-shadows, blurred backdrop filters, and gradient borders.
- **Color Palette**: Tale/emerald main accents, deep blues, soft white cards, and vibrant amber alerts.
- **Dark Mode**: High contrast dark theme with neon brand glow elements.

---

## 2. Layout skeletons

- **Sidebar layouts**: Left-aligned navigation panel with user profile footer and language switch controls.
- **Appointment Wizard**: Multi-step forms (select clinic -> department -> specialty -> doctor -> slot -> book).
- **History Panels**: Segmented list selectors (active vs historic entries).
